## Brief

**What it shows:** A direct two-column comparison of the two agent
orchestration patterns discussed in the post — Crews vs. Flows — ending in
a single "when to use which" decision row, so a reader can screenshot just
this image and keep the decision framework.

**Composition:** Two columns side by side, each headed by the pattern
name. Below each header, 3 short rows: "Control style," "Best for," "Watch
out for." A single full-width row beneath both columns: "Ask yourself:
does this step need judgment, or control?"

**Key text/labels to include:**
- Column headers: "Crews" / "Flows"
- Row labels: "Control style" / "Best for" / "Watch out for"
- Crews column: "Autonomous, role-based" / "Variable paths, creative
  problem-solving" / "Can improvise off-script"
- Flows column: "Event-driven, controlled" / "Fixed sequence, compliance
  steps" / "Less flexible when things vary"
- Bottom row: "Ask yourself: does this step need judgment, or control?"

**Style notes:** Clean, high-contrast, readable at feed thumbnail size —
this is meant to be legible while scrolling, not an artistic piece.
Two-color scheme (one per column) is enough; avoid decorative elements
that don't carry information.

**Suggested dimensions:** 1200×627 (landscape) fits a two-column layout
well for LinkedIn's feed preview — verify current LinkedIn image guidance
before finalizing, platform specs can change.

## Why this visual

The post's core value is a decision framework (which pattern for which
situation) — a side-by-side reference someone can save and act on later
adds something the text alone doesn't: a scannable lookup, not just an
explanation.
